# Design System — depression-is-a-prediction-error

## Thesis the visuals must encode
Depression is not "low serotonin" but a **predictive-coding failure**: the brain has
stopped expecting reward to follow effort, so it stops spending energy. Every scene puts
that idea on screen literally (Okada PRINCIPLES 原則2 = 概念を画面に置く). Never a generic
chart — each segment owns a bespoke still life that means the script.

## Palette
Gray dawn that grades one step toward pale blue across the video (recovery). Hook stays in
gray dawn; the pale-blue grade arrives in seg-05.

## Type stack
Display + kinetic: "Helvetica Neue", Arial — heavy weights for labels, struck for discredited
frames. Captions: same family, 43px, karaoke fill from `--mute` → `--ink`.

## Motion grammar (per visual-methodology RICHNESS)
- No static hold > 15s. The half-glass rim shimmers and dust motes drift continuously.
- ≥1 gear-change per scene. Hook gear-change = "THE WRONG SYSTEM" at ~21.6s.
- Recurring motif: the **reward-pulse that decays before it arrives** (effort → reward link
  that fails) reappears in seg-03 (dopamine flicker) and resolves in seg-05.

## Per-scene visual register

|-----|-----------|------------------------|
| 00 hook | bedside dawn: duvet hill, table ledge, dim phone, half-glass water | reward-pulse fires from EFFORT, decays before reaching REWARD; SADNESS / CHEMICAL IMBALANCE labels discredited |

## HyperFrames invariants (see CLAUDE.md)
Every timed node: `data-start` + `data-duration` + `data-track-index` + `class="clip"`.
Timeline `paused`, registered on `window.__timelines["main"]`. Deterministic only —
mulberry32 seeded PRNG, no `Date.now`/`Math.random`. Captions read `window.seg00`
(generated by `_transcribe.py`).
