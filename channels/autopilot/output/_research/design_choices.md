# Design choices for evolved script v2

> Selection rationale for hooks, reversals, evidence techniques, curiosity mechanisms, meta connections, and long-form retention techniques.
> Reference framework: [[SCRIPT_FRAMEWORK]], [[OKADA_STRUCTURE_ANALYSIS]], [[INTELLECTUAL_HOOKS]], [[CURIOSITY_ENGINE]], [[RECOGNITION_REVERSAL_PATTERNS]], [[EVIDENCE_STACKING]], [[LONGFORM_RETENTION]], [[META_COMMENTARY_PATTERNS]].

## Hook (Phase 0)

**Selected:** H9 衝撃命題先出し型 + H1 逆張り命題型 (combined)

**Why this combination:**
- **H9** is already present in source — "they were exactly wrong" is a shock-proposition. Don't lose it.
- **H1** is the missing layer. The viewer needs an explicit conventional-belief target to overturn. The chosen target: *"if you study what worked, you'll learn what works"* — this is the load-bearing assumption that survivorship bias actually undermines.
- This pairing appears 3× in the 18-video corpus: 火垂るの墓UG226, 千と千尋UG306, On Your Mark — exactly the videos with the strongest 30-day retention metrics in the genre.

**Why NOT other hooks considered:**
- H2 禁断感: works for taboo content; survivorship bias is not taboo, so this would feel forced
- H5 結論先行圧縮: would dump 4 conclusions at once; the script wants progressive revelation
- H6 評価二極化: there is no genuine pro-vs-con controversy on survivorship bias
- H10 レベル構造予告: would commit to a literal "Level 1/2/3" structure; cleaner without it
- H12 自己体験告白: doesn't fit because the writer is positioned as analyst, not protagonist

**Concrete construction for v2:**
1. Beat 1 (visual+H9): Wald + bullet-hole imagery + "exactly wrong"
2. Beat 2 (H1 reverse proposition): name the belief — "the people who study success can't see what's making the data lie. And neither can you."
3. Beat 3 (commitment): "We're going to find the missing planes. Once you see them, every success story you've ever heard rearranges itself."

Total target: 45-55 seconds.

## Reversal cascade (Phases 2, 4, 5)

**Selected:** R4 → R6 → R9 (3-stage cascade with progressive escalation)

| Phase | Reversal type | Content |
|---|---|---|
| Phase 2 (第1反転) | **R4 統計による常識崩壊** | Wald + Brown et al 1995 fund inflation + Tversky-Kahneman 1973 — "your sample is broken at the source" |
| Phase 4 (第2反転) | **R6 美談→構造批判** | "The industries that sell you success advice are themselves the planes that came back. The market for advice has been pre-selected for advice that sold." |
| Phase 5 (第3反転, 大) | **R9 進化論的反転** | "You are not weak. Your pattern-recognition was selected for a world that didn't hide its dead. The fix cannot be more knowledge. It has to be a ritual." |

**Why this cascade:**
- R4 → R6: same logical move (selection bias) applied first to data, then to the *industry that interprets the data*. The viewer sees the bias eat its own meta-level.
- R6 → R9: scale-shift from industry to evolutionary biology. Per [[RECOGNITION_REVERSAL_PATTERNS]]: "第1・第2反転を包含する『より大きなフレーム』であること" — R9 frames the previous two as inevitable consequences of cognitive architecture.
- Cascade depth is 3, which per [[RECOGNITION_REVERSAL_PATTERNS]] is the empirical upper limit ("3段が実用上の上限"). Anything more becomes 疲弊.

**Why NOT other cascades:**
- R4 → R7 多段階連鎖 (4+ steps): would fragment the 20-30 min into 4+ mini-reveals, losing climactic shape
- R4 → R8 表裏二重構造: works for narrative (Spirited Away), doesn't map cleanly to a non-fiction topic
- R4 → R10 スケール反転: similar effect to R9 but R9 has more empirical anchoring in psychology research

## Evidence ordering (Phase 3, and throughout)

**Selected order:** E1 物証 → E4 歴史統計時系列 → E9 実験データ → E3 直接発言引用 → 構造的証拠

Per [[EVIDENCE_STACKING]] basic flow.

**Mapping to specific sources in v2:**

| Layer | Source | Where it lands |
|---|---|---|
| E1 物証 (visual evidence) | Wald's actual diagram (1943) | Phase 0 hook, then revisited in Phase 2 |
| E4 歴史統計 | Mutual fund survivorship inflation (Brown et al 1995) + Bessembinder 2018 4% stat | Phase 3 layer 1 |
| E9 実験データ | Tversky-Kahneman 1973 availability heuristic experiment | Phase 2 anchor |
| E3 制作者発言 (proxy: original thinkers) | Taleb 2001 "silent evidence", Kahneman 2011 "narrative fallacy" — direct quotes from books | Phase 3 layer 2-3 |
| 構造的証拠 | Denrell 2003 "selection on the dependent variable" — meta-bias of management research itself | Phase 4 (acts as evidence FOR R6) |
| E8 想定反論先出し→潰す | "But isn't it still useful to learn from people who succeeded?" — set up and refute in Phase 4 | Phase 4 middle |

**Speed control technique to import:** at minimum 2× use of 「これだけでもすごいが、もっと深い話がある」 -equivalent in English. Functional translations to attempt:
- "And if it stopped there, this would already be a problem. But —"
- "Hold that one. I'm going to come back to it after the next piece, because it actually explains the next piece."
- "If you walked out of here knowing only that, you'd already be ahead of 90% of people making decisions today. We're going further."

## Curiosity mechanisms

**Selected (4 of 12):** C2, C5, C8, C10

| Code | Mechanism | Where it appears in v2 |
|---|---|---|
| **C2** 「後で説明する」先送り多重設置 | 3 deferrals total — each opens a loop that closes 5-15 min later |
| **C5** 対立軸設定型 | Acknowledge the strongest pro-success-story argument once, in Phase 4 ("but doesn't survivor advice contain *some* signal?"), then refute |
| **C8** 「自分も騙されていた」自己更新型 | Narrator briefly admits to a personal version of the bias (career-advice or investing example) at the seam between Phase 3 and Phase 4 |
| **C10** 残り枚数/時間進捗公開型 | 2 progress beats — at Phase 3 start ("we're roughly a third through") and Phase 5 start ("one more layer, then we land") |

**Why NOT others:**
- C1 番号付き謎構造: would force 「謎の1〜N」 framing on a non-fiction essay; awkward
- C3 「まだ序章」: lacks anchor because we are not delivering escalating shock-content
- C4 レベル構造: same reason as H10 above
- C6 有料壁: this is a single open-access video, no paywall
- C7 アンケート: deferred to closing CTA, not midstream
- C9 章区切り: implicit via section transitions
- C11 「語りきれない豊かさ」: would risk feeling like padding
- C12 アクションアイテム: already present in Phase 5 of source — keep but don't over-emphasize

## Meta connection (Phase 5)

**Selected:** M4 進化論的大枠 (primary) + M2 社会論→文明論 (secondary) + M7 媒体批評 (single aside)

**Why M4 primary:**
- The script's killer line is: "your pattern-recognition is doing exactly what it was built to do. The problem is that you're using a stone-age tool in a world that systematically hides the bodies."
- This is already a M4 in embryo. Current script states it but doesn't develop it. v2 promotes it to the central meta-frame.
- Pairs naturally with R9 (進化論的反転) per [[META_COMMENTARY_PATTERNS]]: "[[RECOGNITION_REVERSAL_PATTERNS]] R9 (進化論的反転)と完全対応"

**Why M2 secondary:**
- Connects to attention economy / algorithmic visibility — the second-order survivorship bias of feeds
- Lets us cite a 2020s study to feel current (e.g. algorithm-amplified visibility skew)

**Why M7 aside:**
- One short paragraph noting: this video itself is a survivorship-bias artifact. You're watching it because it has been amplified. The videos that explained this idea poorly didn't make it to you.
- Builds **media-literate trust** without leaning into self-promotion

**Connection bridge phrasings to develop:**
- M4 bridge candidates: "Step back from your own decisions for a moment. Where does this blindness come from?" / "This is not about your discipline. It's about the wiring."
- M7 bridge: "Quick aside that I owe you. You are watching this video because it survived..."

## Long-form retention techniques (20-30 min sustenance)

**Selected (3 of 11):** L7 + L3 + L6

| Code | Technique | Placement |
|---|---|---|
| **L7** エスカレーション構造 | Each Phase 3/4 layer is "more invisible than the last" — Phase 3 ends with "you might think we've seen the deepest version of this. We haven't." |
| **L3** コメディ緩急 | 2-3 deliberately conversational beats to release tension — including a self-aware "I caught myself doing this last week" anecdote |
| **L6** 余談の戦略的挿入 | 1 strategic digression — candidate: a specific failed founder (e.g. Webvan, Pets.com, or a less-known one) whose story is told *as if* it's a success story, then revealed as the missing plane |

**Why NOT others:**
- L1 スケール連続変化: handled by M4 + R9
- L2 異ジャンル横展開: limited budget, less needed for a focused topic
- L4 part/章区切り再スタート: handled by section breaks
- L5 有料パート予告: no paywall
- L8 旅行記ナラティブ: doesn't fit non-narrative content
- L9 実物コレクション紹介: visual, not in script scope
- L10 進捗報告: handled by C10
- L11 多層構造: would require simultaneous parallel narratives — over-engineered for 26 min

## Voice / style guardrails (English audience adaptation)

The Okada structure transfers; the Okada *voice* does not. Target voice = HealthyGamerGG / Better Ideas / Sisyphus 55 register.

**Adopt structurally, do NOT translate phrase-for-phrase:**

| 岡田 function | DON'T do (literal translation) | DO instead (English equivalent) |
|---|---|---|
| 「実はですね」 reveal marker | "Actually, you see..." | "Here's the thing nobody tells you." / "And this is the part that changes everything." |
| 「なんでかっていうと」 | "The reason being that..." | "Here's why." (period — short, punchy) |
| 「覚えておいてください」 | "Please remember this." | "Hold that. We'll come back to it." |
| 「普通の人は気づかない」 | "Normal people don't notice." | "Almost nobody catches this." / "If you've made it this far, you're already further than most." |
| 「ここが面白いんだけども」 | "This is the interesting part." | "And here's where it gets weird." / "Now watch what happens." |

**Avoid:**
- Okada's self-deprecating asides ("僕みたいな凡人が") — doesn't translate; English equivalent feels like false modesty
- Live-feel interruptions ("staff, is the survey ready?") — script is not live
- Tightly Japanese pop-culture analogies — substitute culturally-equivalent ones (e.g., not 「アベンジャーズ・シビルウォー = 南北戦争」 unless naturally needed)

**Keep:**
- The induction-not-deduction structure (build evidence, let conclusion crystallize)
- The "viewer is not stupid" stance — explain the cognitive architecture, never the cognitive failure
- 段階的zoom-in (whole → specific → detail)

## Schema decisions for output

`script.json` will preserve the original schema and add ONE new field per section:

```jsonc
{
  "heading": "...",
  "narration": "...",
  "visual_note": "...",
  "duration_estimate_seconds": 180,
  "okada_meta": {                      // NEW
    "phase": 3,                        // 0..6
    "hook_types": ["H1","H9"],         // present in this section
    "reversal": "R4",                  // primary reversal applied
    "evidence": ["E1","E9","E3"],
    "curiosity": ["C2","C10"],
    "meta_connection": null,           // M-type if this section makes the meta jump
    "longform_techniques": ["L7"]
  }
}
```

This keeps backward compatibility with anything reading the existing JSON, while making the structural choices machine-inspectable.
